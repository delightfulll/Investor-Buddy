# Finance App

> A Robinhood-inspired iOS stock trading simulator built with SwiftUI — **mostly generated by Claude Code** as an experiment to push the limits of AI-assisted development.

>My mom uses this app for investing lol
---

## Overview

This app mimics the core experience of Robinhood: a live watchlist, an interactive price chart styled after Robinhood's signature gesture-driven graph, a paper trading engine, portfolio tracking, and a technical-analysis prediction engine that forecasts price movements across multiple timeframes. Real market data is pulled directly from the **Yahoo Finance API**.

---

## Tech Stack & Libraries

```
Language       Swift 5.9+
Framework      SwiftUI
Concurrency    Swift Structured Concurrency (async/await, TaskGroup, actor)
Reactive       Combine
Architecture   MVVM
```

### APIs

| API | Usage |
|-----|-------|
| **Yahoo Finance v8 Chart API** | Price history, OHLCV data, candlestick intervals |
| **Yahoo Finance v11 Quote API** | Real-time quotes, company fundamentals |
| **Yahoo Finance v10 quoteSummary** | Company description, sector, industry, financial stats |
| **Yahoo Finance v1 Screener** | Market movers — top gainers, losers, most active, undervalued growth, small caps |
| **Yahoo Finance Search API** | Symbol & company name lookup |
| **Yahoo Finance Crumb/Cookie Auth** | Cookie + crumb handshake required for v10 authenticated endpoints |

> No third-party networking libraries are used — all requests are made with Swift's native `URLSession`.

## Robinhood-Style Interactive Chart

One of the core goals of this project was to **replicate Robinhood's signature chart interaction**:

- A smooth line chart rendered with SwiftUI `Path` and `Canvas`
- A scrubber line that follows your finger across the chart
- The price and timestamp update live as you drag
- Color shifts green/red based on whether the price is above or below the open
- Time range selector: `1D · 1W · 1M · 3M · YTD · 1Y`
- Full-screen chart zoom view

## View Models

The app follows strict MVVM — every screen has a dedicated `@MainActor ObservableObject` view model. All business logic, data fetching, and state live in the view models; views are purely declarative.

| View Model | Responsibility |
|---|---|
| `AccountViewModel` | Account balances, holdings, buy/sell execution, fund transfers |
| `HomeViewModel` | Watchlist quotes, market movers (gainers/losers), precious metals |
| `StockDetailViewModel` | Price chart, company info, time range selection, multi-timeframe predictions |
| `StockRecommendationViewModel` | Scans live market screeners and surfaces top AI-scored stock picks |
| `SearchViewModel` | Symbol/company search, watchlist add/remove/reorder |
| `PortfolioViewModel` | Portfolio summary, holdings, and watchlist aggregation |
| `StockTradingSheetViewModel` | Buy/sell order input, validation, and execution |
| `TransferSheetViewModel` | Fund transfers between Checking, Savings, and Buying Power |
| `MoverStockDetailViewModel` | Resolves a market mover into a full stock object for the detail view |

## Prediction Engine

`StockPredictionEngine` is a pure Swift technical analysis engine with no external ML dependencies. It runs entirely on-device.

### Indicators Used

| Category | Indicators |
|----------|-----------|
| **Trend** | MA, EMA, WMA, MACD, ADX, Parabolic SAR, Ichimoku Cloud, Trend Consistency |
| **Momentum** | RSI, Rate of Change (ROC), Stochastic Oscillator, CCI, Williams %R |
| **Volatility** | Bollinger Bands, ATR, Keltner Channels |
| **Volume** | OBV, VWAP, CMF, MFI |
| **Support/Resistance** | Pivot Points, Fibonacci Retracement, Price Action |
| **Mean Reversion** | Z-Score, RSI Divergence |
| **Candlestick Patterns** | Doji, Hammer, Engulfing, Gap |

### Prediction Horizons

Each stock detail screen shows predictions for **6 timeframes**:

```
1 Day  →  Short-term signals weighted heavily
3 Days →  Short-term signals weighted heavily
1 Month → Short + medium-term blend
6 Months → Medium-term indicators
1 Year   → Medium-term + historical baseline blend
10 Years → Long-term + ~8% historical annual return baseline
```

Long-term predictions compound a blended monthly rate (indicator signal + historical baseline) to prevent compounding noise from dominating multi-year forecasts.
